# out/bin/

`build.ps1 -Deploy` deja aquí `forgecraft.exe`, la hoja `forgecraft.qss`, las DLL de Qt y de MinGW, las de mpg123 y LAME, las carpetas `platforms`, `iconengines`, `imageformats` y `licenses`.

Este contenido no se versiona (está en `.gitignore`). Descarga el paquete de la Release para obtener una copia lista para ejecutar.
